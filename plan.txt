I. PROJECT OVERVIEW
---------------------------------------------------------

Goal:
-----
Tee Time Snipe helps golfers catch open tee times that fit their schedule before others do. 
It monitors supported booking platforms (starting with ForeUp) and immediately notifies the user 
when a matching tee time opens up.

Core Philosophy:
----------------
- Respect provider Terms of Service (no auto-booking)
- Focus on timely alerts, simple user experience, and accurate notifications
- Validate demand before scaling infrastructure
- Build leanly on Always-Free and developer-friendly cloud tools

V. HOW THE SYSTEM WORKS
---------------------------------------------------------

Flow Overview:
---------------
1. User signs up or logs in (Supabase auth).  
2. Newly created user auto-assigned Free tier (DB trigger).  
3. Device requests notification permission and registers with Expo → token stored in `user_profiles`.  
4. User sets a tee-time alert by choosing course, date range, and preferred time window.  
5. Backend validates alert creation vs. tier quota limit.  
6. ForeUp adapter scans course availability → normalized into UTC tee times.  
7. APScheduler periodically executes tier-based alert checks.  
8. `alert_service` matches availability vs. alert criteria → inserts `alert_notifications` for new matches.  
9. Summary push notifications sent to users for new matches (once per alert per cooldown window).  
10. User receives push → opens app → navigates to “My Alerts” → sees tee times & books.
