I. PROJECT OVERVIEW
---------------------------------------------------------

Goal:
-----
Tee Time Snipe helps golfers catch open tee times that fit their schedule before others do. 
It monitors supported booking platforms (starting with ForeUp) and immediately notifies the user 
when a matching tee time opens up.

Core Philosophy:
----------------
- Respect provider Terms of Service (no auto-booking)
- Focus on timely alerts, simple user experience, and accurate notifications
- Validate demand before scaling infrastructure
- Build leanly on Always-Free and developer-friendly cloud tools

V. HOW THE SYSTEM WORKS
---------------------------------------------------------

Flow Overview:
---------------
1. User signs up or logs in (Supabase auth).  
2. Newly created user auto-assigned Free tier (DB trigger).  
3. The device requests notification permission and registers with Expo → token stored in Supabase.  
4. User sets a tee-time alert by choosing course, date range, and preferred window.  
5. Backend validates alert creation versus `max_alerts` restriction.  
6. ForeUp adapter scans course data → normalized availability saved.  
7. `scanner.py` periodically checks for matches → triggers Expo push notification via `push_service.py`.  
8. User receives a mobile notification → tap opens app and navigates to relevant page.  
9. Stripe handles upgrades/downgrades → webhook syncs membership tier automatically.  
10. UI reflects current tier, quotas, and prompts to upgrade when limits reached.
