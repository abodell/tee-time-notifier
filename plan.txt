I. PROJECT OVERVIEW
---------------------------------------------------------

Goal:
-----
Tee Time Snipe helps golfers catch open tee times that fit their schedule before others do. 
It monitors supported booking platforms (starting with ForeUp) and immediately notifies the user 
when a matching tee time opens up.

Core Philosophy:
----------------
- Respect provider Terms of Service (no auto-booking)
- Focus on timely alerts, simple user experience, and accurate notifications
- Validate demand before scaling infrastructure
- Build leanly on Always-Free and developer-friendly cloud tools

V. HOW THE SYSTEM WORKS
---------------------------------------------------------

End‑to‑End Flow (Current):
1. User creates alerts for tee times; unauthenticated users are prompted to sign up or log in.  
2. Upon signup, a `user_profile` is created automatically and assigned to the Free tier.  
3. Users on Free tier can add limited alerts and normal scan frequency.  
4. On the “Upgrade” page, the app fetches available membership tiers via backend.  
5. When a user selects a higher tier, the app calls `/membership/upgrade`.  
6. Backend creates or reuses a Stripe Customer and opens hosted Checkout.  
7. User completes purchase and Stripe redirects them to success URL.  
8. Webhook fires → updates user’s `membership_tier_id` in Supabase.  
9. When reopening the app, `/membership/profile/{user_id}` displays the new tier.  
10. Profile tab now shows plan description, limits, and subscription tier summary.  
11. App UX includes button loading state and responsive feedback during checkout.  
12. Alerts, profile, and upgrade pages all follow consistent styling and spacing.
