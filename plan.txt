I. PROJECT OVERVIEW
---------------------------------------------------------

Goal:
-----
Tee Time Snipe helps golfers catch open tee times that fit their schedule before others do. 
It monitors supported booking platforms (starting with ForeUp) and immediately notifies the user 
when a matching tee time opens up.

Core Philosophy:
----------------
- Respect provider Terms of Service (no auto-booking)
- Focus on timely alerts, simple user experience, and accurate notifications
- Validate demand before scaling infrastructure
- Build leanly on Always-Free and developer-friendly cloud tools

V. HOW THE SYSTEM WORKS
---------------------------------------------------------

End-to-end flow (current MVP):
1. User can browse for courses and set alert preferences (holes, date/time window).  
2. Non‑authenticated users are prompted to sign in or sign up.  
3. After authentication, alert preferences are saved to the backend FastAPI API.  
4. On successful login, the user is redirected back to Create Details with previous input state preserved.  
5. Alert creation sends payload to `/alerts/create` → Supabase insert confirmed.  
6. Toast notifications confirm success or display errors instantly.  
7. “My Alerts” page renders all stored alerts from `/alerts/user/{user_id}`.  
8. Users can delete alerts with an immediate update to the UI and DB.  
9. Authentication is persistent and auto-renews via AsyncStorage.  
10. Backend normalizes tee-time data (ForeUp currently live; others coming).  
11. When matches occur, a notification event is logged (push flow to be implemented).  

Frontend Highlights:

- Searchable course selector (to be enriched next with live course names)

- Fully themed light/dark Paper integration

- Supabase Auth persistence and silent token refresh  
- Global toasts for all feedback (login, alert creation, deletion)  
- Managed Expo workflow (works on iOS + Android with no native dependencies)
