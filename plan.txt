---------------------------------------------------------
I. PROJECT OVERVIEW
---------------------------------------------------------

Goal:
-----
Tee Time Snipe helps golfers catch open tee times that fit their schedule before others do. 
It monitors supported booking platforms (starting with ForeUp) and immediately notifies the user 
when a matching tee time opens up.

Core Philosophy:
----------------
- Respect provider Terms of Service (no auto-booking)
- Focus on timely alerts, simple user experience, and accurate notifications
- Validate demand before scaling infrastructure
- Build leanly on Always-Free and developer-friendly cloud tools

V. HOW THE SYSTEM WORKS
---------------------------------------------------------

End-to-end flow (current MVP):
1. User can browse for courses and set alert preferences (holes, date/time window).
2. Non‑authenticated users are prompted to sign in or sign up.
3. After authentication, alert preferences are saved to the backend API.
4. Backend normalizes tee-time data from ForeUp and checks for matches.
5. When matches occur, a notification event is logged (push coming next phase).
6. All new users and alerts are stored in Supabase for unified tracking.

Frontend Highlights:
--------------------
- Searchable course selector querying Supabase `courses`
- Sticky bottom tab navigation (Home, My Alerts, Profile)
- Theming system shared across all components
- Date/Time picker modals with native behavior and live validation banners
- Time-range aware picker system (Preferred Start ↔ End Time)
- Session persistence via Supabase Auth

The frontend now implements the key complete flow for “Create Alert” with full visual polish.
